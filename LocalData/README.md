# Private local data

This directory is reserved for real local development data and is ignored by Git except for this policy and `.gitkeep`.

Possible contents include databases and sidecars, private reading lists, imports, exports, backups, logs, cover caches, local configuration, and security-scoped bookmark data. None of these files may be copied into `SampleData/` or committed.

Application production storage will use the appropriate app-specific macOS Application Support location; this repository directory is only a development convention.
