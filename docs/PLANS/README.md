record stage boundaries and evidence; the current authorized user/controller
task defines what may execute now, including gates and retry limits, within
[AGENTS.md](../../AGENTS.md). Historical prompts and command blocks are not new
execution authority. A model or documentation update does not reset budgets
or change a recorded acceptance decision.

Do not advance a product milestone while its prerequisite acceptance has
failing checks, undocumented changes, unresolved private-data findings, or
unreviewed technology assumptions. A separate, explicitly authorized
maintenance task may proceed within its own scope while that milestone stays
blocked; completing the maintenance does not accept or advance the milestone.
